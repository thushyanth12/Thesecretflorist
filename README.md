# 🌸 The Secret Florist

> A premium flower bouquet e-commerce website designed with a modern **Blush Pink** aesthetic, allowing customers to browse handcrafted bouquets, customize their orders, manage a shopping cart, and place orders seamlessly through WhatsApp.

---

## 📖 Overview

The Secret Florist is a responsive e-commerce website created for a flower shop that offers handcrafted bouquets for birthdays, anniversaries, weddings, and other special occasions.

The website provides an elegant shopping experience with a beautiful user interface, product categorization, bouquet customization, shopping cart functionality, and WhatsApp-integrated ordering.

## 💻 Usage

1. Browse available bouquets.
2. Select your preferred bouquet.
3. Customize the bouquet if required.
4. Add products to the cart.
5. Review the cart.
6. Proceed to WhatsApp Checkout.
7. Send the order confirmation to the florist.
